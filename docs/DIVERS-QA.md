# 《深潜者》反馈验收（2026-10-07）

《Divers》是合集第 27 款，工程内部 ID 为 19。

## 译名

采用《深潜者》。英文简介为 “CONTROL DYLAN, ORLOK, AND THYME AS THEY EXPLORE THE WATERY DEPTHS.”，日文简介同样强调探索深海。遗骸、古老守护者、仪式面具、蠕动血肉等调查文本进一步确立了神秘而幽暗的探索氛围。《潜水员》准确但偏向现代职业名称，《深潜者》更贴合三位主角的行动和游戏气质。

原版资料明确称《月猫》是《Barbuta》的精神续作；《Divers》的简介与开发历史没有明确声明三作属于同一世界观。译名判断依据游戏文本和玩法，项目介绍不添加这项推测。

修改前已在隔离游戏中复现上述四类错位。原版以字符位置乘 8px 定位图标，且其精灵字体把 `%` 当作空白图标格；Zpix 中文宽度不同，百分号也会显示，导致中文被图标覆盖并出现多余符号。

`UFO50_CHS_draw_divers_reward` 仅在中文分支拆分前缀、图标槽和后缀；图标继续由原版精灵绘制。`UFO50_CHS_divers_icon_x` 使用当前中文字体测量前缀。领取、掉落、库存、概率、存档及其他语言的处理逻辑保持原流程。
