# UFO 50 简体中文汉化 v0.2.0 测试版

这是第 51 款隐藏内容的完整汉化版本，保持完整离线安装：下载、完整解压后双击安装；不需要 Python、Node.js、PowerShell 模块或联网下载依赖。安装完成后，请在游戏语言设置中手动切换到“中文”。

## 主要内容更新

- 完整汉化第 51 款隐藏内容《瘴气塔》，覆盖场景叙事、人物对话、物件调查、任务提示、结局与职员表。
- 保留隐藏内容发现链所需的英文身份、终端命令、内部名、八位代码与文件扩展名，确保中文化不会破坏原版解谜。
- 中文终端遵循官方日文本地化规则：自然语言使用中文，玩家实际输入的协议保持原样。

## 按游戏

### 《瘴气塔》

- 新增 547 条逐条翻译和自校的正文，正式中文名定为《瘴气塔》。
- 保留 `GREGORY MILK`、`GREG-MILK`、`STEN MURZBACH` 等参与英文拼写谜题的身份文本，并维持员工档案的英文姓氏排序。
- 保留 `EXEC`、`LIST`、`INFO`、`HELP`、`MIAS`、八位代码、`.UFO` 与原型程序命令；自然语言谜语、环境叙事和角色对话使用中文。
- 未发行软件首次出现时同时显示中文名与英文原名，后续使用中文简称，避免玩家失去原文线索，同时控制文本长度。
