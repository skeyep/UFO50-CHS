# 《诡石堡》名词审阅

本轮参考官方英、日、法、德、意、葡、西七语，结合装备分类、商店、宝箱、战斗和 NPC 对话代码，复核 95 个物品名与五处堡垒相关正文。修订四个武器名，统一标题、正文地名和跨游戏引用，共七个文本字段。

## 地名

`npc_agartha_04` 英文说明 Malus 从 Black Citadel Grimstone 统治地狱，日文为「あんこくじょう『グリムストーン』」。意、葡、西文也明确 Grimstone 是堡垒专名，法文表达为黑石堡垒。中文定为《诡石堡》，保留“诡石”的音意结合。“黑色堡垒”“堡垒”等通称继续沿用。

## 历史名物资料

- [Royal Museums Greenwich：七管齐射枪](https://www.rmg.co.uk/collections/objects/rmgc-object-2517)：说明 Henry Nock 供货的七管齐射结构。结合游戏 NOCKER 的变体名称与枪械分类，将“重击者”改为“诺克排枪”。
- [Powerhouse Museum：平底船枪](https://collection.powerhouse.com.au/object/238697)：说明大型猎禽枪固定在平底船上使用。游戏西班牙文 BARCA 提供船的语义线索，将 PUNTER 改为“平底船枪”。
- [NRA Museums：Deringer 口袋手枪](https://www.nramuseum.org/the-museum/the-galleries/the-prospering-new-republic/case-30-the-gold-rush/henry-deringer-percussion-pocket-pistol.aspx)：结合日文ディレンジャー、法文 DERINGER 与手枪分类，将 DERANGER 改为“德林杰手枪”。[美国国会图书馆藏品](https://www.loc.gov/item/2010630694/)提供 Derringer 实物资料。
- [National Army Museum：燧发 Musket](https://collection.nam.ac.uk/detail.php?acc=1992-08-199--1)：Musket 的历史实例包含燧发点火，游戏未指定火绳点火，采用“火枪”通称。

NOCKER／PUNTER／DERANGER 与历史枪名的关联依据为拼写、官方译名线索、装备身份及上述实物资料。游戏正文未展开枪械制造史；游戏中 b 类沿原霰弹枪图标和战斗机制。

## 语境与保留项

“恶魔号角”的原使用提示明确吹奏并召唤巨兽；RATLING 的具体历史型号典故待考；“米特莱机枪”沿现有缩写音译；怪物 KNOCKER“矿坑鬼”与武器 NOCKER 分开处理。饰品、躯干服装和鞋按原装备槽区分，保留此前身体部位修订。
