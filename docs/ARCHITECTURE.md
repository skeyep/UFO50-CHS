# 技术结构

## 文本层

UFO 50 的外置文本按语言和内部游戏 ID 分目录保存。补丁复用原日语槽作为中文槽：`0_Text.json` 负责合集通用界面，`m_Text.json` 负责合集资料，`1_Text.json` 至 `50_Text.json` 负责各子游戏。

除元数据外，外置文件通常是 Base64 包装的 UTF-8 JSON。构建器保留原键名、布局字段、尾逗号和控制符，只替换经过审核认可的文本值。

## GameMaker 绘制补丁

除 `draw_text_ext()` 外，部分子游戏会先用 `scrStringSplit()` 或 `string_line_breaks()` 得到行数组，再逐行调用 `draw_text()`。这类界面必须在调用点按 Zpix 实际字高推进纵坐标，并结合真实文本框宽度和底部边界复核，不能依赖通用包装函数自动修正。

`payload/patch-font.csx` 由 UndertaleModTool 在用户本机应用到用户自己的原版 `data.win`，主要负责：

- 初始化官方原版 Zpix 8px；
- 中文槽字体全路由；
- 按实际中文字宽处理逐字绘制和居中；
- 对显式 `string_line_breaks` 调用以 `wc × 8px` 还原文本框宽度，并让 `draw_text_ext` 使用调用位置提供的真实像素宽度；
- 不把资源中的 `*_wc / *_wl` 截断上限当作权威显示框，只在掌握实际绘制宽度的路径按 Zpix 实际字宽断行；
- 让消息框和 `draw_text_ext` 共用像素换行与常见行首禁则规则，并按运行时字高修正多行步进；
- 把连续星号、`{0}`、`[1]` 等动态字段作为不可拆分整体，避免换行破坏后续变量替换；
- 在《鸟族争霸》中混合使用原版 `fontAvianos` ASCII 图标和 Zpix 中文，恢复资源、兵种、建筑与状态图标；
- 让三类通用居中 helper、档案名称光标及固定信息面板按运行时实际字宽布局；
- 在中文槽中把三类文字绘制调用统一上移 1px；
- 修复语言加载、旧档案语言、合集详情、中文游戏名与铺满初始化；
- 加入仅中文槽可见的署名和用途声明。

补丁不修改字体轮廓，不把 `data.win` 或字体二进制放入源码仓库。Release 为离线安装单独封装作者发布的原版字体。

## 安装器

安装器由 ASCII PowerShell 5.1 兼容脚本组成，避免旧控制台中文编码造成解析问题。中文文本只作为二进制安全文件复制；控制台提示使用英文。

玩家安装阶段不访问网络。Release 构建阶段从固定 URL 取得 Zpix、UndertaleModTool CLI 与对应源码归档并校验 SHA-256；安装器再次校验包内依赖，失败时不会修改游戏文件。文件替换开始后的错误会触发本轮备份恢复。

## 公开与私有边界

公开仓库包含译文、构建器、补丁脚本、安装器和生成后的中文槽文件。以下内容只存在于维护者本地，并由 `.gitignore` 明确排除：

- 原版或补丁后的 `data.win`；
- `ufo50.exe` 与其他游戏二进制；
- 原始英文、日文资源；
- UndertaleModTool 程序与字体二进制（只在 Release 构建阶段封装，不提交到源码仓库）；
- 反编译输出、历史备份与测试安装目录。
