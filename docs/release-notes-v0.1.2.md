# UFO 50 简体中文汉化 v0.1.2 测试版

这是持续维护中的排版修订版，保持完整离线安装：下载、完整解压后双击安装；不需要 Python、Node.js、PowerShell 模块或联网下载依赖。安装完成后，请在游戏语言设置中手动切换到“中文”。

## 主要表现修复

- 修复连续中文在原版英文未换行的区域只显示一行或横向超出文本框的问题。
- 修复若干手写逐行绘制界面仍按固定 8px 推进，导致中文相互压叠、说明出框或最后一行被裁切的问题。

## 按游戏

### 《摇滚岛》

- 开场剧情会按照真实文本框宽度完整切为多行滚动，长篇中文不再只显示第一行。

### 《开派对》

- 右侧效果说明、门、通讯录和筹备提示改用安全宽度与实际中文行高；长词条不会越过右边界或上下重叠。

### 《恶魔爆破》《维因格》《坎帕内拉 2》《巴布塔》

- 修复各自显式切行界面的中文行距；《坎帕内拉 3》滚动字幕同时修复底部裁切。

## 实现

- 以原版调用点给出的真实宽度和 Zpix 运行时度量断行，不再用英文字符数推断中文容量。
- 对仍由游戏逐行 `draw_text()` 的界面，中文分支采用实际行高；其他语言不受影响。
- 文档统一移除不准确的“人工”限定表述。
