# v1.2.4 译文修改完整列表

本轮修订 113 个字段。参考官方英、日、法、德、意、葡、西七语，并结合原技能效果、物品与族群设定、红骑士赠剑的连续对白，以及各游戏原制作名单显示场景校对。游戏标题与既有创意译名沿用。

## 主要取舍

- Study 通过观察敌人学习招式，技能名用“学习”，动作提示写清“观察……的招式”。
- Forage 的原事件会获得药草及食材，采用“采集”；Harvest 是“死亡”的即死招式，采用“收割”。
- Protein 指蛋白质，原文没有 powder。去掉粉末形态的限定，同步获得提示、升级与商店名称。
- Hexan 的“纤族”来自官方日文的另一个族名。英语及多数欧洲语言保留 Hex 词根，结合角色六角外形统一为“六角族”，同步 72 处引用。
- 红骑士原句跨两页，中文按原赠剑事件重组，保留曾想亲手击败领主、再将使命托付玩家的含义。
- 制作名单保留人员名、职务、品牌与输入代码，补译其中 23 行面向玩家的正文。`BENE-DIKT`、`WEAK-TOWN`、`VIPS-ONLY`、`MAKE-GLEE` 原样保留。
