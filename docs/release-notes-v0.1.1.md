# UFO 50 简体中文汉化 v0.1.1 测试版

这是首次完整流程版本 `v0.1.0` 之后的排版与兼容性修订版，仍以 Pre-release 形式发布。安装包保持完整离线：下载并解压后双击安装，不需要 Python、Node.js、PowerShell 模块或联网下载依赖；安装完成后请在游戏语言设置中手动切换到“中文”。

本次主要更新：

- 中文换行改为依据实际绘制框和 Zpix 8pt 运行时字宽，修复英文不换行但中文已经出框的情况。
- 修复 `rmInit` 初始化崩溃、详情页过早换行、多行文字重叠、档案名光标错位和“游玩时间”页出框。
- 修复《鸟族争霸》资源、兵种、建筑和状态图标显示成 `$`、`%` 或普通字母的问题。
- 通用居中函数改用中文实际像素宽度，修复设置菜单、确认窗口、游戏标题和选关标题等位置逐字偏移。
- `GOLFARIA` 更新为《高尔夫之歌》，`MINI & MAX` 更新为《小米妮和大麦克》，正文统一“小米妮 / 大麦克”，`HOT FOOT` 更新为《烫脚球》。
- 50 款子游戏、合集菜单和元数据重新通过控制符、占位符与布局审计，并完成本轮实机验收。

完整逐项更新见 [CHANGELOG.md](https://github.com/skeyep/UFO50-CHS/blob/main/CHANGELOG.md)。

> 汉化：Skeyep_目目。由 Skeyep_目目与 GPT-5.6 Sol 协作翻译和自校，未使用批量机翻服务。仅供学习交流，禁止商业使用。
