# UFO 50 简体中文汉化

Windows Steam 版《UFO 50》的简体中文汉化补丁，最新发布版本为 **v1.0.3**。

由 **Skeyep_目目**与 **GPT-5.6 Sol** 协作完成。

## 汉化内容

- 50 款子游戏及隐藏内容的剧情、对话、菜单和提示。
- 合集菜单、设置、档案、操作说明、成就与花园资料。
- 游戏名称、简介、开发历史和资料留言。
- 中文像素字体，以及换行、行距、居中和图标混排适配。

解谜需要的终端命令、代码和英文拼写保留原样。

## 下载与安装

适用于 **Windows 10/11 的 Steam 版《UFO 50》**。安装包自带所需字体与工具，安装时无需联网，也无需另装运行环境。

1. 前往 [下载页面](https://github.com/skeyep/UFO50-CHS/releases/latest)，下载 `UFO50-CHS-v1.0.3.zip`。
2. 将 ZIP 完整解压到一个文件夹。
3. 关闭游戏，双击 `Install-UFO50-CHS.cmd`。
4. 安装器会自动查找 Steam 游戏目录；需要手动选择时，选中包含 `ufo50.exe` 的文件夹。
5. 安装完成后启动游戏，按 `Esc` 打开菜单，在语言设置中选择 **“中文”**。

补丁使用原日语语言槽。安装时会自动备份原文件，备份保存在游戏目录的 `chs-backup/` 中，卸载时用于恢复。

## 升级与卸载

**升级：**关闭游戏，先运行旧安装包中的 `Uninstall-UFO50-CHS.cmd`，再运行新版安装包中的 `Install-UFO50-CHS.cmd`。

**卸载：**关闭游戏，双击 `Uninstall-UFO50-CHS.cmd`，恢复安装前的游戏文件。卸载后备份目录仍会保留。
