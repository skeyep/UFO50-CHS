# UFO 50 简体中文汉化

Windows Steam 版《UFO 50》简体中文民间汉化。当前版本为 **v0.1.0 测试版**，已经跑通完整的翻译、字体适配、安装、备份和卸载流程，但仍可能存在语境、排版或漏译问题。

汉化补丁：**Skeyep_目目**

本汉化由 **使用 GPT-5.6 Sol 协作完成**：AI 参与逐条翻译与自校，维护者负责方向、术语决策和最终验收。

> 本项目仅供学习交流，禁止商业使用。本项目与 UFO 50 官方、Mossmouth、Zpix 作者及 UndertaleModTool 团队均无隶属或授权关系。

## 玩家安装说明

### 系统要求

- Windows 10/11
- Steam 正版《UFO 50》
- Release 已封装经哈希校验的官方工具和官方原版字体，安装过程无需联网
- 不需要手动安装 PowerShell 模块、Python、Node.js 或 UndertaleModTool

### 下载与安装

1. 前往 [Releases](https://github.com/skeyep/UFO50-CHS/releases) 下载 `UFO50-CHS-v0.1.0-test.zip`。
2. **完整解压** ZIP，不要直接在压缩包内运行。
3. 关闭《UFO 50》。
4. 双击 `Install-UFO50-CHS.cmd`。
5. 安装器会自动寻找 Steam 游戏目录；找不到时会让你手动选择包含 `ufo50.exe` 的文件夹。
6. 安装完成后启动游戏，按 `Esc` 打开菜单，进入语言设置，把原日语槽切换为 **“中文”**。

安装器不会强制修改语言或存档。切换一次中文后，之后会按游戏自身的配置正常保存。

### 卸载

双击 `Uninstall-UFO50-CHS.cmd`。卸载器会读取安装时创建的记录，恢复原版 `data.win`、原日语文本和安装前字体。备份目录会保留，不会自动删除。

### 安装器具体做了什么

安装器只处理用户本机合法持有的游戏文件：

1. 校验游戏版本和 Release 包清单；
2. 在游戏目录的 `chs-backup/` 中创建带时间戳的完整备份；
3. 校验 Release 内置的 UndertaleModTool CLI 与对应 GPLv3 源码归档；
4. 校验 Release 内置、未经修改的官方原版 Zpix；
5. 在用户电脑上从原版 `data.win` 构建中文绘制补丁；
6. 安装 52 个中文文本文件和字体；
7. 再次核对安装后的哈希，并写入可安全卸载的记录。

Release 不包含 `data.win`、游戏 EXE、原始英日文本或反编译工程。为保证中国大陆等网络环境下可以离线安装，Release 内置官方原版 Zpix、官方 UndertaleModTool CLI 及其对应 GPLv3 源码；源码仓库只保留版本、哈希、下载地址和许可文本，不提交这些二进制文件。

## v0.1.0 已完成内容

- 50 款子游戏的文本均与 GPT-5.6 Sol 逐条协作翻译并初校，但汉化字体的排版和一些符号仍有问题，需要QA校对。
- 完成合集菜单、设置、档案、语言、游戏说明、历史资料、操作提示、成就和花园资料的中文化。
- 中文游戏名、年份、收藏图标、详情分页和 13 字换行规则已适配合集界面。
- 中文槽统一路由到支持完整中文字形的 Zpix，解决部分游戏有译文但整块文字消失的问题。
- 修复逐字绘制写死 8px 导致汉字相互覆盖的问题，中文字距和居中按实际字宽计算。
- 中文文字在游戏绘制层统一上移 1px，不修改字体轮廓或字体指标。
- 修复“铺满”在首次启动时错误使用整数倍率的问题，1080p、2K、4K和超宽屏均按实际分辨率动态计算。
- 标题页中文槽显示 `汉化：Skeyep_目目`，语言页显示“仅供学习交流，禁止商业使用”。
- 一键安装、自动备份、哈希校验和一键卸载流程已经过隔离安装测试。

## 基本汉化映射

游戏目前没有官方中文槽，因此补丁复用原日语槽：

| 游戏资源 | 汉化用途 |
| --- | --- |
| `ext/JAPANESE/0_Text.json` | 合集菜单、设置、档案和通用 UI |
| `ext/JAPANESE/m_Text.json` | 游戏名、简介、历史、提示和资料留言 |

| 日语字体路由 | 在中文槽中统一路由至 Zpix 8px |

## 翻译与发布工作流

项目以英文原文为语义基准，参考官方日文处理语境、专名和版面限制。每款游戏按“AI 逐条翻译与自校→维护者决定方向和术语→控制符审计→生成中文槽→最终验收”的方式推进。

发布时从干净原版 `data.win` 构建，校验预期哈希；Release 通过白名单复制，只允许安装脚本、中文文本、补丁逻辑、说明文件以及经过固定哈希校验的第三方离线依赖进入 ZIP。随后在隔离目录执行一次安装与卸载，确认：

- 52 个中文文件与包内哈希完全一致；
- 补丁后的 `data.win` 哈希符合版本配置；
- 卸载后恢复到原版哈希；
- 包内不存在游戏二进制、字体、原始语言资源或反编译内容。

详细说明见 [维护工作流](docs/WORKFLOW.md) 和 [技术结构](docs/ARCHITECTURE.md)。
