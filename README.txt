UFO 50 简体中文汉化
由 Skeyep_目目与 GPT-5.6 Sol 协作完成。

安装
1. 完整解压安装包，关闭游戏。
2. 双击 Install-UFO50-CHS.cmd；如需手动选择，选中包含 ufo50.exe 的游戏文件夹。
3. 启动游戏，在 Esc 菜单的语言设置中选择“中文”。

升级：关闭游戏，先运行旧版安装包中的 Uninstall-UFO50-CHS.cmd，再运行新版的安装入口。
检查：运行 UFO50-CHS\Check-UFO50-CHS.cmd，查看版本并检查游戏数据和字体。
还原：关闭游戏，运行 UFO50-CHS\Uninstall-UFO50-CHS.cmd，恢复安装前的游戏文件。

支持 Windows 10/11 的 Steam 版 UFO 50。安装包包含字体和工具，安装时无需联网。汉化使用日语语言槽，原文件自动备份到游戏目录的 chs-backup 文件夹。

下载与反馈：https://github.com/skeyep/UFO50-CHS

UFO 50 Simplified Chinese Patch

Install
1. Extract the entire archive and close the game.
2. Run Install-UFO50-CHS.cmd. If prompted, select the game folder containing ufo50.exe.
3. Start the game and select 中文 in the Esc menu's language settings.

Upgrade: close the game, run Uninstall-UFO50-CHS.cmd from the previous package, then run the new installer.
Check: run UFO50-CHS\Check-UFO50-CHS.cmd to see the version and check the game data and font.
Restore: close the game and run UFO50-CHS\Uninstall-UFO50-CHS.cmd to restore the original files.

Supports the Windows 10/11 Steam version of UFO 50. The package includes its tools and font and installs offline. It uses the Japanese language slot and backs up original files to chs-backup in the game folder.

Download and feedback: https://github.com/skeyep/UFO50-CHS
