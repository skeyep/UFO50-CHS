UFO 50 简体中文汉化 v1.0.1
由 Skeyep_目目与 GPT-5.6 Sol 协作完成。

汉化内容：
50 款子游戏及隐藏内容，以及合集菜单、设置、档案、操作说明、成就、花园资料和游戏介绍。
解谜需要的终端命令、代码和英文拼写保留原样。

安装：
1. 将安装包完整解压到一个文件夹。
2. 关闭游戏，双击 Install-UFO50-CHS.cmd。
3. 安装器会自动查找 Steam 游戏目录；需要手动选择时，选中包含 ufo50.exe 的文件夹。
4. 安装完成后启动游戏，按 Esc 打开菜单，在语言设置中选择“中文”。

适用于 Windows 10/11 的 Steam 版 UFO 50。
安装包自带所需字体与工具，安装时无需联网，也无需另装运行环境。
补丁使用原日语语言槽。原文件会自动备份到游戏目录的 chs-backup/，卸载时用于恢复。

升级：
关闭游戏，先运行旧安装包中的 Uninstall-UFO50-CHS.cmd，再运行新版安装包中的 Install-UFO50-CHS.cmd。

卸载：
关闭游戏，双击 Uninstall-UFO50-CHS.cmd，恢复安装前的游戏文件。卸载后备份目录仍会保留。
