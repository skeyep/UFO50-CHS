UFO 50 简体中文汉化 v0.1.0 测试版
简体中文汉化：Skeyep_目目
仅供学习交流，禁止商业使用。

安装：
1. 完整解压本压缩包。
2. 双击“Install-UFO50-CHS.cmd”。
3. 安装器会自动寻找 Steam 版 UFO 50、备份原文件、下载并校验官方工具与官方原版 Zpix，然后完成安装。
4. 首次启动游戏后，进入语言设置，把原来的日语选项切换为“中文”。安装器不会修改存档或强制更改语言。

卸载：
双击“Uninstall-UFO50-CHS.cmd”。安装器会使用首次安装时创建的备份恢复原文件；备份本身不会被删除。

注意：
- 仅支持 Windows Steam 版及 release-config.json 中记录的 data.win 版本。
- 安装时需要联网下载 UndertaleModTool CLI 与官方原版 Zpix；用户不需要手动下载或配置它们。
- 本包不包含 UFO 50 的 data.win、游戏程序、英文/日文原始文本、反编译工程或修改后的字体。
- Zpix 文件保持作者发布的原始哈希；中文基线上移 1px 由游戏绘制包装函数完成。
- 补丁修正了“铺满”在首次启动时错误采用整数倍率的问题，按每台电脑的实际分辨率动态计算，不写死 2K。
- 标题页中文槽显示“汉化：Skeyep_目目”；语言页显示“仅供学习交流，禁止商业使用”。
- 全部 50 款子游戏、合集菜单、游戏资料与操作说明均已进行人工翻译和自校；没有使用机器翻译服务。
- 这是首次跑通完整流程的 0.1.0 测试版，不代表最终完成版。遇到排版、语境或漏译问题，请在项目页面反馈。
