UFO 50 简体中文汉化 v0.2.0 测试版
简体中文汉化：Skeyep_目目
由 Skeyep_目目与 GPT-5.6 Sol 协作完成：AI 参与逐条翻译与自校，维护者负责方向、术语决策和最终验收；未使用批量机翻服务。
仅供学习交流，禁止商业使用。

安装：
1. 完整解压本压缩包。
2. 双击“Install-UFO50-CHS.cmd”。
3. 安装器会自动寻找 Steam 版 UFO 50、备份原文件、校验包内官方工具与官方原版 Zpix，然后完成离线安装。
4. 首次启动游戏后，进入语言设置，把原来的日语选项切换为“中文”。安装器不会修改存档或强制更改语言。

卸载：
双击“Uninstall-UFO50-CHS.cmd”。安装器会使用首次安装时创建的备份恢复原文件；备份本身不会被删除。

注意：
- 仅支持 Windows Steam 版及 release-config.json 中记录的 data.win 版本。
- 安装时无需联网；本包已封装官方 UndertaleModTool CLI、对应 GPLv3 源码和官方原版 Zpix。
- 本包不包含 UFO 50 的 data.win、游戏程序、英文/日文原始文本、反编译工程或修改后的字体。
- Zpix 文件保持作者发布的原始哈希；中文基线上移 1px 由游戏绘制包装函数完成。
- 补丁修正了“铺满”在首次启动时错误采用整数倍率的问题，按每台电脑的实际分辨率动态计算，不写死 2K。
- 中文会按实际绘制框像素宽度自动换行；动态字段不会在控制符内部被拆开。
- 《鸟族争霸》的资源、兵种、建筑和状态字符仍使用原版图标字体，与 Zpix 中文混合显示。
- 修复中文详情、消息框与子游戏文本的行距和换行，并让“游玩时间”等固定面板自适应单行或双行布局。
- 修复档案名光标、中文标题、设置菜单和确认窗口等位置的实际字宽居中。
- 游戏名更新为“高尔夫之歌”“小米妮和大麦克”“烫脚球”，正文姓名统一为“小米妮 / 大麦克”。
- 标题页中文槽显示“汉化：Skeyep_目目”；语言页显示“仅供学习交流，禁止商业使用”。
- 全部 50 款常规子游戏、第 51 款隐藏内容、合集菜单、游戏资料与操作说明均由 Skeyep_目目与 GPT-5.6 Sol 逐条协作翻译并自校；未使用批量机翻服务。
- 第 51 款《瘴气塔》的自然语言内容已汉化；终端命令、内部名、八位代码和英文拼写谜题身份保持可正常解谜。
- 这是持续维护中的 0.2.0 测试版，不代表最终完成版。遇到排版、语境或漏译问题，请在项目页面反馈。
